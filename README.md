# Exp - 2 LIBRARY MANAGEMENT SYSTEM

AIM:
To study the problem statement, SRS document and draw all the UML diagrams of a Library Management System.

SRS (Procedure):
Step 1: Problem Identification
The main problem is the need for a fast, secure, and automated system that helps manage library operations efficiently. The system should allow students and staff to search books, issue and return books, manage records, and reduce manual paperwork while improving accuracy.

Step 2: Requirement Analysis
Identify users: Student, Librarian, Admin Functional requirements: Login, search books, issue/return books, renew books, manage records. Non-functional requirements: Security, speed, reliability, and ease of use.

Step 3: System Design
Draw UML diagrams to represent the system:
